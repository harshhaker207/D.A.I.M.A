================================================================================

💡 TIPS FOR BEST RESULTS
================================================================================

✅ GOOD REFERENCE PHOTOS:
   - Clear, well-lit photos
   - Front-facing or near-frontal face
   - No shadows on the face
   - Add 2-3 photos per person
   - Different angles and lighting conditions

❌ AVOID:
   - Blurry photos
   - Very dark or overexposed photos
   - Side profile or extreme angles
   - Faces too small or too large in frame
   - Multiple people in one reference photo

🆘 TROUBLESHOOTING
================================================================================

Problem: "No faces detected in image"
Solution: 
   - Make sure photo shows a clear face
   - Try with better lighting
   - Use front-facing photos

Problem: "Person not being recognized"
Solution:
   - Add more reference photos (try 3-4)
   - Use photos from different angles
   - Ensure good lighting in reference photos
   - Check that face is clearly visible

Problem: "Webcam not working"
Solution:
   - Check if camera is properly connected
   - Try a different program to test camera first
   - Close other applications using camera
   - Restart the program

Problem: "Program won't start"
Solution:
   - Make sure all .onnx files are present
   - Check Python is installed (python --version)
   - Install required packages: pip install opencv-python numpy

Problem: Multiple faces not detected
Solution:
   - Ensure faces are well-lit and clearly visible
   - Move closer to camera if faces are too small
   - Check that multiple people are within frame
